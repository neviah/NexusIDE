# NexusIDE Private Alpha

This private alpha includes the Code-OSS editing workbench, native Git workflows, web language services, optional language-tooling guidance, free-first model routing, and supervised OpenCode Agent mode.

Artifacts are currently unsigned. Verify downloads against `SHA256SUMS` before installation. See `docs/SETUP.md`, `docs/PRIVACY.md`, and `docs/TROUBLESHOOTING.md` for setup and known limitations.
